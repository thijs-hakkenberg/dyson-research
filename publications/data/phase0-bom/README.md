# Phase 0 BOM snapshot

`phase-0-bom.json` is a copy of `src/lib/data/phase-0-bom.json` from the web platform
repository (`thijs-hakkenberg/dyson`, commit 96923ae, 2026-11-12). It is generated there by
`scripts/build-bom-data.js` from the regenerated Phase 0 consensus, and is the input to
`phase0_cost_risk.py` and `phase0_chain_model.py`. Refresh it whenever the BOM numbers change.
